# AIカンプ依頼シート / AI Comp Brief

生成AIで作られたカンプや支給素材を使う制作依頼で、**何を参考にし、何を成果物に使い、誰が何を確認するか**を短時間でそろえるための無料・公開フォーマットです。

> **これはライセンスでも法律上の免責を自動成立させる契約書でもありません。** 依頼内容を記録し、必要な合意を促す道具です。個別契約、利用規約、適用法が優先します。権利侵害の第三者に対する法的責任を、このシートだけで消すことはできません。重要案件では法律の専門家に確認してください。

**[無料Webフォームを開く](https://hatteinc.github.io/ai-comp-brief/)**

## 使い方

1. [Webフォーム](https://hatteinc.github.io/ai-comp-brief/)を開き、案件と各素材を入力します。サーバーへの送信はありません。
2. 生成された依頼文をコピーし、発注書・見積書・契約書に添付します。PDFが必要ならブラウザーの印刷で保存できます。手書きやテキスト編集には[Markdown版](template.md)も使えます。
3. 印刷用の[PDF](AIカンプ依頼シート.pdf)も使えます。入力項目の解説は[記入ガイド](docs/guide.md)にあります。
4. 依頼者と制作者が、未確認事項、追加費用、変更時の承認を確認してから着手します。

Webフォームは静的ファイルです。GitHub Pages は `main` ブランチのルートから公開しています。フォームの入力内容はサーバーに送信しません。

PDFを再生成する場合は `reportlab` と日本語TrueTypeフォントを用意し、`AI_COMP_FONT=/path/to/font.ttf python scripts/build_pdf.py` を実行します。

## 3つの基本指定

| 表示 | 依頼の意味 | 初期の扱い |
| --- | --- | --- |
| **参考のみ** | カンプは方向性の共有用 | 具体的な表現は再制作し、支給画像をそのまま掲載しない |
| **支給素材を使用** | 指定した素材を成果物に使用 | 使用範囲と権利根拠を素材ごとに記録する |
| **権利処理済みに差替** | 生成素材の箇所を代替素材に変更 | ストック等の購入者・費用・ライセンス条件を決める |

「支給素材を使用」と指定しても、権利確認や第三者請求への対応が自動的に完了するわけではありません。

## 記録する項目

- 素材ごとのAI使用有無、使用箇所、生成ツール・モデル・版、プロンプトと参照入力、生成日
- プロンプトを共有できない場合の理由、共有先・保存先、機密情報の扱い
- 参照元・既存作品・人物・商標・ロゴ・フォント・ストック素材とその利用許諾
- 商用利用、加工、再配布、広告、地域、期間などの使用範囲
- 権利確認担当、未確認点、差替判断、第三者から申立てがあった時の通知と対応
- 制作者側のAI利用許可、入力データの扱い、納品物、変更時の承認
