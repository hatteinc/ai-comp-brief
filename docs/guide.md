# 記入ガイド・チェックリスト

## まず選ぶ

- [ ] **参考のみ**：カンプの構成や雰囲気を参考に、具体的な画像・文章・ロゴ等は新しく作る。
- [ ] **支給素材を使用**：指定素材を成果物に入れる。素材単位で許諾と用途を確認する。
- [ ] **権利処理済みに差替**：AI画像などをストック素材・自社素材・新規撮影等に置き換える。

案件全体に一つの指定を選んでも、素材ごとに例外を記録する。たとえば「全体は参考のみ、正式ロゴだけそのまま使用」。

## 依頼前チェック

### 1. 素材台帳

- [ ] 支給ファイルごとに名称、用途、提供者、生成AI使用の有無を記した（不明も選択可能）。
- [ ] AI使用ありの素材について、ツール・モデル・版、生成日、プロンプト、参照画像・入力データを記した。共有できない場合は理由と確認方法を記した。
- [ ] 人物・顔・声、商標・ロゴ、フォント、ストック素材、既存作品の参照を特定した。
- [ ] 使用予定媒体、商用利用、加工、公開地域、期間、二次利用に対する許諾や条件を確認した。
- [ ] 生成サービスの利用規約や契約プランで、予定する利用が許されるか確認した。

### 2. 権利と対応

- [ ] 依頼者が権利を持つもの、第三者から許諾を得たもの、未確認のものを区別した。
- [ ] 類似作品の懸念、既存作品を模倣する指示、参照画像の出典などを記録した。
- [ ] 制作者が確認できる範囲と、専門調査の要否・費用を決めた。
- [ ] 第三者から申立てを受けた際の通知先、公開停止判断、調査、差替費用、損害負担を個別契約で決めた。
- [ ] 「依頼者が責任を持つ」の対象を、依頼者が提供した素材・指示・許諾情報に限定して具体化した。制作者自身の故意・過失や独自に追加した素材の扱いも決めた。

### 3. 制作と納品

- [ ] 制作者が生成AIを使ってよいか、使える工程、使う場合の開示方法を決めた。
- [ ] 秘密情報や個人情報を外部AIサービスに入力してよいか決めた。
- [ ] 差替素材の購入者、ライセンス名義、費用、再利用条件を決めた。
- [ ] 納品物の形式、編集可能データ、素材一覧、権利情報、確認・修正回数を決めた。
- [ ] 依頼の変更や未確認事項が判明した場合の一時停止・再見積り・承認方法を決めた。
